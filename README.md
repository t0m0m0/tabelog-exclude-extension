# 食べログ 除外キーワードフィルタ

食べログの検索結果から、**店名またはジャンル**に指定キーワードを含む店舗を非表示にする Chrome 拡張機能です。

- 検索バーの右に追加される入力欄にキーワードを入力するとリアルタイムで絞り込まれます
- 複数キーワードはスペース・カンマ・読点区切り
- キーワードは `chrome.storage.sync` に自動保存され、次回以降も維持されます
- 検索結果が全件非表示になった場合は次のページへ自動スキップします

## 開発版の読み込み方

1. Chrome で `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」→ このリポジトリのフォルダを選択
4. 食べログの検索結果ページを開く

コードを編集したりブランチを切り替えたりしたあとは、`chrome://extensions` の拡張機能カードにある再読み込みボタン（⟳）を押し、食べログのタブもリロードしてください。

## 手動での動作確認

検索バー右の「除外キーワード（店名・ジャンル）」欄にキーワードを入力し、以下を確認します。

| 確認項目 | 例 |
| --- | --- |
| 店名に含む店が消える | `すき家` のようなチェーン店名を入力 |
| ジャンルに含む店が消える（店名になくても） | `焼肉` を入力すると、店名に「焼肉」が無くてもジャンルが焼肉の店が消える |
| エリア名では消えない | `渋谷` を入力しても、渋谷エリアというだけの店は消えない（店名に「渋谷」を含む店だけ消える） |
| 件数表示 | 「◯件（うち◯件を非表示）」が付く |
| 保存 | ページをリロードしてもキーワードが残り、フィルタが効いたままになる |
| 自動スキップ | 1ページの全件が消えるキーワードを入れると次のページへ移動する |

## 自動テスト

拡張機能を実際に読み込んだ Chromium（Playwright）で、食べログの検索結果マークアップを再現したページに対して動作を検証します。`tabelog.com` へのリクエストは `test/fixtures/` の再現ページに差し替えられますが、URL は `tabelog.com` のままなので `manifest.json` の `matches` に従って `content.js` が本番と同じ経路で注入されます。

```sh
npm install
npx playwright install chromium   # 初回のみ
npm test
```

Node.js 20 以上が必要です。テストは PR と `main` への push で GitHub Actions でも実行されます（`.github/workflows/test.yml`）。

## Chrome ウェブストア用のパッケージ

配布用の zip には拡張機能の実体だけを含めてください（`node_modules/`、`test/`、`.github/`、`package*.json` は不要です）。

```sh
zip -r tabelog-exclude-extension.zip \
  manifest.json content.js content.css icons
```

## プライバシー

入力したキーワードはブラウザ内にのみ保存され、外部サーバーへの送信は一切ありません。詳細は [PRIVACY_POLICY.md](PRIVACY_POLICY.md) を参照してください。
