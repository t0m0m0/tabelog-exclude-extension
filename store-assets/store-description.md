# Chrome Web Store 掲載情報

## 短い説明

食べログの検索結果から、指定したキーワードを店名またはジャンルに含むお店を自動で非表示にします。チェーン店や苦手なジャンルをフィルタリングして、本当に行きたいお店を素早く見つけましょう。

---

## 詳細説明

食べログ 除外キーワードフィルタ

食べログの検索結果を、自分好みにフィルタリングできるChrome拡張機能です。

【使い方】
検索バーの右側に追加される「除外キーワード（店名・ジャンル）」欄にキーワードを入力してください。
入力した文字を店名またはジャンルに含むお店が、リアルタイムで非表示になります。

【こんな使い方ができます】
・チェーン店を除きたい →「マクドナルド ガスト すき家」のように複数入力
・苦手なジャンルを除きたい → 「焼肉 ホルモン」など（店名に含まれていなくてもジャンル表記で判定します）
・特定の屋号を非表示にしたい → 店名の一部を入力するだけ

【主な機能】
・店名とジャンルの両方をキーワード判定の対象にできます
・複数キーワード対応（スペースまたはカンマ区切り）
・キーワードは自動保存。次回アクセス時も設定が維持されます
・何件非表示になったか一目でわかるカウンター表示
・そのページの全件が非表示になった場合は、理由をその場に表示（勝手にページ移動しません）
・食べログのデザインに馴染むシンプルなUI

【対応ページ】
食べログ（tabelog.com）の全ページ

プライバシーについて：入力したキーワードはお使いのブラウザ内にのみ保存されます。外部サーバーへの送信は一切行いません。
